# Janela Cósmica

## Autor

Lays Evangelista Sales — Matrícula 22551447

## Descrição

A Janela Cósmica é uma aplicação web que permite escolher uma data e visualizar a Astronomy Picture of the Day, também conhecida como APOD, disponibilizada pela NASA.

A aplicação apresenta a imagem ou vídeo astronômico, o título, a data, a explicação científica e os créditos da mídia.

## API utilizada

- **Nome:** NASA Astronomy Picture of the Day — APOD
- **Portal:** https://api.nasa.gov/
- **Documentação:** https://github.com/nasa/apod-api
- **Endpoint utilizado:** https://api.nasa.gov/planetary/apod

## Parâmetros utilizados

- `api_key`: chave de acesso da API
- `date`: data escolhida pelo usuário
- `thumbs`: permite obter miniatura quando o conteúdo é um vídeo

## Funcionalidades

- Consulta da imagem astronômica por data.
- Botão para consultar a imagem de hoje.
- Exibição do título.
- Exibição da data.
- Exibição do tipo de mídia.
- Exibição da explicação científica.
- Exibição dos créditos.
- Link para abrir a mídia original.
- Tratamento de erros.
- Layout responsivo para computador e celular.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API pública da NASA
- GitHub Pages
